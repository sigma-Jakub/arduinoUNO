# Arduino UNO Tutorial Portfolio

## About the course and author

Arduino UNO Tutorial is a [Youtube series](https://www.youtube.com/watch?v=fJWR7dBuc18&list=PLGs0VKk2DiYw-L-RibttcvK-WBZm8WLEP) uploaded by Paul McWhorter explaining basics of Arduino UNO, components used to interact with it and basic physics to better understand key concepts of microcontroller working proccesses.

## Hardware Components Used

### Core & Interconnects
* Arduino UNO
* Solderless Breadboard
* Parallel Shift Register (74HC595)

### Displays & Indicators
* LED
* RGB LED
* Active Buzzer

### Sensors & Inputs
* Temperature and Humidity Sensor (DHT11)
* Ultrasonic Distance Sensor (HC-SR04)
* Photoresistor (GL5516)
* Joystick Module
* Pushbutton
* Potentiometer
* Tilt Switch

### Actuators & Motors
* Micro Servo (SG90)
* DC Motor
* Stepper Motor (28BYJ-48)

## Key Concepts Learned

### Digital Systems & Number Formats
* Binary Numbers
* Hexadecimal Numbers

### Electrical Engineering & Circuit Design
* Ohm's Law
* Simple Circuit Design
* Pull-Up / Pull-Down Resistor Logic

### Signal Modulation & Control
* Pulse Width Modulation (PWM)

## Repository Structure

### The repository has been divided into three main parts:
* [01_Demos](https://github.com/sigma-Jakub/arduinoUNO/tree/main/01_Demos) - basic code used for testing each individual hardware component
* [02_Exercises](https://github.com/sigma-Jakub/arduinoUNO/tree/main/02_Exercises) - complex programs combining multiple hardware components and advanced software
* [03_Notes](https://github.com/sigma-Jakub/arduinoUNO/tree/main/03_Notes) - digital compilation of notes taken throughout the course

## Additional Information

* Certain hardware components, such as the **DC Motor** and **Ultrasonic Distance Sensor (HC-SR04)**, are intentionally omitted from both [01_Demos](https://github.com/sigma-Jakub/arduinoUNO/tree/main/01_Demos) and [02_Exercises](https://github.com/sigma-Jakub/arduinoUNO/tree/main/02_Exercises) directories. Because the primary goal of completing this course was to explore unfamiliar components and advanced software concepts, I chose to not re-implement modules I had already mastered. My prior experience and practical application with these specific components can be found in my [BattleBot_BB016](https://github.com/sigma-Jakub/BattleBot_BB016) repository.
